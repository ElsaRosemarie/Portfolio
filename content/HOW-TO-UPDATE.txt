HOW TO UPDATE THE WEBSITE (no code editor needed)
================================================

Everything lives on GitHub. When you save a change, the site rebuilds
automatically in about 2–3 minutes.

Open your repository in a browser:
https://github.com/ElsaRosemarie/Portfolio


─── CHANGE PAGE TEXT (easiest way) ────────────────────────────────

Page text is now plain .txt files — no JSON commas to worry about.

1. Open the folder:  content  →  pages
2. Click the page you want:
     home.txt
     about.txt
     contact.txt
     workshops.txt
3. Click the pencil icon  ✏️  Edit this file
4. Change the text
5. Scroll down →  Commit changes  →  Commit changes

HOW THE TEXT FILE WORKS
• Leave a blank line between paragraphs
• Use *italic* and **bold** for emphasis
• Use [link text](https://url) or [link text](/page) for links
• No quote marks or commas needed around paragraphs

Small settings (greeting, buttons, etc.) live in matching .meta.json files:
  home.meta.json
  workshops.meta.json
These files are optional and much smaller than before.


─── CHANGE EMAIL, INSTAGRAM, OR LINKEDIN ───────────────────────────

1. Open:  content  →  site.json
2. Edit the "links" section
3. Commit changes

Tips for site.json:
• You may add // comments at the start of a line
• A comma after the last item is OK — the site fixes that automatically


─── CHANGE GALLERY ORDER ───────────────────────────────────────────

You can use EITHER method (or both):

METHOD A — order.txt (recommended for exact control)
1. Open:  Afbeeldingen portfolio  →  WORK  (or RESEARCH)
2. Click  order.txt  →  pencil icon  ✏️
3. Move lines up or down (one project name per line)
4. Commit changes

METHOD B — rename folders with a number at the start
Rename a project folder like this:
  01 - Queer Zine Toekomstboeren
  02 - Spring storm
  03 - Once Upon a Time

Lower numbers appear first. Projects not in order.txt still follow
these numbers when they are added at the end.

Order goes left to right, then top to bottom.


─── ADD OR REMOVE WORK / RESEARCH ─────────────────────────────────

ADD a project folder:
  Afbeeldingen portfolio  →  WORK  →  Add file  →  Create new file
  Type:  My Project Name/photo.jpg   (creates a folder + image)
  Add a cover image in WORK/ named like:  My Project Name dig, com.png
  Add the project name to order.txt (or use 01 - My Project Name)
  Commit changes

REMOVE a project: delete its folder and its line in order.txt

HIDE without deleting: put a minus before the name in order.txt
  Example:  - Draft project


─── IMAGE CATEGORIES (work gallery filters) ───────────────────────

Add tags at the END of the cover filename, before the extension:

  trad  = Traditional
  dig   = Digital
  com   = Commissioned
  other = Other

Examples:
  My piece trad.jpg
  My piece dig, com.png        (appears in two filters)


─── SINGLE-IMAGE ILLUSTRATIONS (title + description in popup) ─────

Single images in WORK/ show only a title until you add a description.
The popup then looks the same as multi-image projects like Queer Zine.

Easiest: create a description file next to the image.

  Image:        Afbeeldingen portfolio/WORK/Thesis cover trad.jpg
  Description:  Afbeeldingen portfolio/WORK/Thesis cover trad.description.txt

Write your text in that file. Blank line = new paragraph.
Use *italic*, **bold**, and [links](url) like page text.

Alternative: add an entry in  content/projects/work.json  keyed by title.


─── PROJECT TEXT (folder projects) ───────────────────────────────

Add  description.txt  inside the project folder:

  Afbeeldingen portfolio  →  WORK  →  My Project  →  description.txt

Write your text there. Separate paragraphs with a blank line.
Use [link text](url) for links. No JSON needed.

Alternative: edit  content/projects/work.json  or  research.json


─── IMAGE ORDER WITHIN A PROJECT ──────────────────────────────────

Inside a project folder, add  images.txt  (one filename per line).

  Afbeeldingen portfolio  →  WORK  →  My Project  →  images.txt

Example:
  photo-cover.jpg
  detail-1.png
  detail-2.png

Images not listed are appended at the end. Use  -filename  to hide one.


─── CHANGE IMAGES ON A PAGE ─────────────────────────────────────

Replace image files in  Afbeeldingen portfolio:

  HOME/          → homepage hero + portrait
  ABOUT/         → about page portrait
  WORKSHOPS/     → workshops banner

Keep the same filename, or ask a developer to update the image mapping.


─── CUSTOM DOMAIN ─────────────────────────────────────────────────

1. Open  content/site.json
2. Set  "basePath"  to  ""  (empty)
3. Set  "customDomain"  to your domain, e.g.  "elsarosemarie.com"
4. Commit changes
5. In GitHub:  Settings  →  Pages  →  Custom domain


─── IF SOMETHING BREAKS ───────────────────────────────────────────

After committing, check the deploy status:
  GitHub  →  Actions  tab  →  latest green checkmark = live

Use  History  on the file to undo your last edit.

Common mistakes:
• Forgetting a blank line between paragraphs in .txt files
• Typo in a project name inside order.txt
• Broken link brackets: use [text](url) with no spaces inside the brackets
