HOW TO UPDATE THE WEBSITE (no code editor needed)
================================================

Everything lives on GitHub. When you save a change, the site rebuilds
automatically in about 2–3 minutes.

Open your repository in a browser:
https://github.com/ElsaRosemarie/Portfolio

Full tutorial with examples: see README.md in the repo root.


─── CHANGE PAGE TEXT ───────────────────────────────────────────────

Page text is plain .txt files — no JSON commas to worry about.

1. Open:  content  →  pages
2. Click the file you want (home.txt, about.txt, contact.txt, workshops.txt)
3. Click the pencil icon  ✏️  Edit this file
4. Change the text
5. Commit changes

HOW THE TEXT FILE WORKS
• Leave a blank line between paragraphs
• Use *italic* and **bold** for emphasis
• Use [link text](https://url) or [link text](/page) for links
• No quote marks or commas needed around paragraphs

Small settings (greeting, buttons) live in matching .meta.json files:
  home.meta.json
  workshops.meta.json


─── CHANGE EMAIL, INSTAGRAM, OR LINKEDIN ───────────────────────────

1. Open:  content  →  site.json
2. Edit the "links" section
3. Commit changes

Tips for site.json:
• You may add // comments at the start of a line
• A comma after the last item is OK — the site fixes that automatically


─── CHANGE GALLERY ORDER ───────────────────────────────────────────

Use  order.txt  — one project name per line.

1. Open:  Afbeeldingen portfolio  →  WORK  (or RESEARCH)
2. Click  order.txt  →  pencil icon  ✏️
3. Move lines up or down
4. Commit changes

Order goes left to right, then top to bottom.

Example:
  Queer Zine Toekomstboeren
  Spring storm
  Once Upon a Time

HIDE without deleting: put a minus before the name in order.txt
  Example:  - Draft project


─── ADD OR REMOVE WORK / RESEARCH ─────────────────────────────────

ADD a project folder:
  Afbeeldingen portfolio  →  WORK  →  Add file  →  Create new file
  Type:  My Project Name/photo.jpg   (creates a folder + image)
  Add the project name to order.txt
  Commit changes

REMOVE a project: delete its folder and its line in order.txt


─── TEXT UNDER A SINGLE-IMAGE ILLUSTRATION ────────────────────────

Create a description file next to the image — same name + .description.txt

  Image:         WORK/Thesis cover trad.jpg
  Description:   WORK/Thesis cover trad.description.txt

Write your text in that file. Blank line = new paragraph.
Use *italic*, **bold**, and [links](url) like page text.


─── PROJECT TEXT (folder projects) ───────────────────────────────

Add  description.txt  inside the project folder:

  Afbeeldingen portfolio  →  WORK  →  My Project  →  description.txt


─── IMAGE ORDER WITHIN A PROJECT ──────────────────────────────────

Inside a project folder, add  images.txt  (one filename per line).

  Afbeeldingen portfolio  →  WORK  →  My Project  →  images.txt

Images not listed are appended at the end. Use  -filename  to hide one.


─── IMAGE CATEGORIES (work gallery filters) ───────────────────────

Add tags at the END of the cover filename, before the extension:

  trad  = Traditional
  dig   = Digital
  com   = Commissioned
  other = Other


─── IF SOMETHING BREAKS ───────────────────────────────────────────

After committing, check:  GitHub  →  Actions  →  green checkmark = live
Use  History  on the file to undo your last edit.

Common mistakes:
• Forgetting a blank line between paragraphs in .txt files
• Typo in a project name inside order.txt
• Broken link brackets: use [text](url) with no spaces inside the brackets
